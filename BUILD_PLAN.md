# Build plan for Click For Parts

## 1. Client assets checklist
- [ ] Logo
- [ ] Domain confirmed
- [ ] Company description
- [ ] Services
- [ ] Phone
- [ ] WhatsApp
- [ ] Email
- [ ] Physical location
- [ ] Videos
- [ ] Photos
- [ ] Client logos
- [ ] Social links
- [ ] CTA text

## 2. Design system
- Confirm brand colours
- Confirm typography
- Define button styles
- Define content cards and section spacing
- Finalise navigation structure

## 3. Build order
1. Create semantic HTML
2. Add base CSS and responsive CSS
3. Add minimal JavaScript for navigation and form validation
4. Replace placeholders with final content
5. Configure form processing on the hosting platform
6. QA on mobile and desktop
7. Deploy and hand over documentation

## 4. Form architecture
A static frontend cannot send email directly. Use a server-side handler such as PHP or a form service behind the form.

## 5. QA checklist
- Domain resolves
- HTTPS works
- Navigation works
- CTA links work
- WhatsApp link works
- Phone link works
- Email link works
- Form submission works
- Mobile layout is usable
